# For Aliza 🌟

A small cheer-up website: 10 cat GIFs with sounds, then a song with an encouraging message.

## Run it
Open `index.html` in a browser.

## Put it online (free)
1. Go to https://app.netlify.com/drop
2. Drag this whole folder onto the page.
3. Site settings → Change site name → `aliza`

## Change things
- Words, timing, volume: top of `script.js`
- Colors and sizes: `style.css`
- GIFs and songs: the `assets` folder
